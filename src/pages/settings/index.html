Modey Launcher

Le Modey Launcher est construit à partir du EML Template, le template officiel de l'écosystème open-source EML (Electron Minecraft Launcher), puis entièrement adapté à la plateforme Modey : interface sur-mesure, authentification Modey, architecture multi-serveurs et fichiers isolés par serveur.

Toute la logique Minecraft — authentification, téléchargements vérifiés, lancement du jeu — est assurée par EML Lib, dans une architecture « 1 compte, 1 launcher, N serveurs ».

 EML Project — https://emlproject.com/  EML Template sur GitHub  EML Lib sur GitHub
